\section{Platform at a glance}\label{platform-at-a-glance}

Persian conversational RAG for credit-reporting questions. Production code lives in Git submodules; the umbrella owns pins, deploy scripts, contracts, and evaluation. Release \texttt{v13\_1405-07-06} indexes \textbf{18 documents / 1,123 chunks}. Guardrails uses a HurtLex allowlist of \textbf{28} lemmas. Subspace ambiguity is computed (\texttt{enabled=true}) and does not route by default (\texttt{route=false}).

\section{Architecture and request path}\label{architecture-and-request-path}

Browser → WebUI \texttt{:13000} → Orchestrator \texttt{:8100} → Guardrails input → KB retrieve → \texttt{build\_context} (≤20 chunks, context 9000) → Guardrails generate → Manager \texttt{:9000} → citations back to WebUI. Sticky subspace decays after \textbf{3} generic turns. Evidence floor \textbf{0.15}. Ambiguity margin \textbf{0.08}.

\section{Knowledge base}\label{knowledge-base}

Hybrid stack: tantivy BM25 (k1=1.5, b=0.75, keyword boost ×3, synonym beam 5) + MiniLM 384-d HNSW (m=16, ef=64) → RRF k=60 → BGE-m3 rerank (fusion α=0.7) → EntityList inject (≥0.6). Redis cache TTL 600 s. Warm hybrid search \textasciitilde{}\textbf{55 ms}. Published Hit@5 on the prior corpus (v11): \textbf{0.9306}.

\section{Orchestrator}\label{orchestrator}

Never dials Gemma directly. Keyword boosts: cheque 3.5; facilities 3.0; general 2.5. Clients use \texttt{trust\_env=False} so Squid does not capture localhost. Checkpoint sticky scope with \texttt{MemorySaver} / \texttt{request\_id}.

\section{Guardrails}\label{guardrails}

Deterministic signals → policy judge (\texttt{gemma} / \texttt{mizan} / \texttt{hybrid}) → LLM self-check. Fail-closed on errors. PII-IR (mod-11 / mod-97) masks; secrets hard-block. Policy pin \texttt{ics-credit-v1.0.0}. Thresholds published with the stack: toxicity/hate 0.80, PII 0.90, injection 0.85.
