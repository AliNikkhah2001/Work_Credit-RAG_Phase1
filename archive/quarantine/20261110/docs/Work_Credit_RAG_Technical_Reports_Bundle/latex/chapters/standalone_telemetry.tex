\chapter{Logging, Telemetry, and Monitoring}\label{logging-telemetry-and-monitoring}

\textbf{Section summary.} Work Credit RAG treats observability as a \emph{layered} contract: KB returns per-stage \texttt{stage\_ms} (also Redis-cached); the orchestrator rolls node timings into \texttt{stage\_timing\_ms} and an optional \texttt{AuditTrail}; Langfuse v2 (or host JSONL) records spans; \texttt{components/tracing} persists SQLite + JSONL pipeline cards; guardrails and the inference manager keep their own stores. Operators read that stack at three ports: Langfuse v2 on \textbf{:3001}, the parent fallback collector on \textbf{:3000}, and LangGraph Studio on \textbf{:2024}. Studio run inputs must include \texttt{request\_id}; without it, sticky memory and trace envelopes have nothing to join on. E2E latency is dominated by \textbf{generation}, not retrieval---warm KB search is tens of milliseconds while chat turns sit near five seconds---so optimizations favor RAM-first retrieval, context trim, and TRT-LLM serving over further BM25 micro-cuts.

\section{\texorpdfstring{2 Knowledge-base \texttt{stage\_ms} and Redis}{2 Knowledge-base stage\_ms and Redis}}\label{knowledge-base-stage_ms-and-redis}

Every successful \texttt{POST\ /search/api} response includes a \texttt{stage\_ms} object written in \texttt{kb\_manager/web/routes/search.py} as each leg finishes: BM25 (tantivy RAM index), dense MiniLM encode + HNSW/pgvector lookup, Reciprocal Rank Fusion (\texttt{k=60}), BGE-m3 cross-encoder rerank, and \texttt{total}. The same object is stored with the cached SearchSteps payload under Redis (\texttt{KB\_REDIS\_TTL}, default \textbf{600s}) or an in-memory fallback when Redis is down; exact-cache hits typically return in \textbf{2--7 ms} and never cache error responses. Operators can therefore diagnose ``dense vs rerank'' without attaching a profiler---\texttt{jq\ \textquotesingle{}.stage\_ms\textquotesingle{}} on a warm curl is the day-to-day tool.

\section{\texorpdfstring{3 Orchestrator timings, AuditTrail, and \texttt{ORCH\_DEBUG}}{3 Orchestrator timings, AuditTrail, and ORCH\_DEBUG}}\label{orchestrator-timings-audittrail-and-orch_debug}

Graph nodes call \texttt{record\_timing(state,\ stage,\ elapsed\_ms)} (\texttt{state.py}) so retrieve, clarify, \texttt{build\_context}, \texttt{guarded\_generate}, format, and retry/broaden paths accumulate into \texttt{state{[}"stage\_timing\_ms"{]}}. On the buffered OpenAI chat path, \texttt{api.py} builds a Pydantic \texttt{AuditTrail} that copies those timings together with retrieved chunks, guard signals, context preview, subspace ambiguity fields, and wall \texttt{latency\_ms}. Setting \texttt{ORCH\_DEBUG=1} turns on app-level INFO logging and enables opt-in context diagnostics inside \texttt{build\_context} so engineers can see what reached Gemma.

The buffered path stores that \texttt{AuditTrail}. The SSE path streams tokens from Guardrails, finalizes citations and metadata, and keeps traces updating.

\section{4 Langfuse v2 HTTP and host fallbacks}\label{langfuse-v2-http-and-host-fallbacks}

\texttt{work\_rag\_orchestrator/tracing.py} posts direct HTTP to Langfuse v2 on \textbf{:3001}: envelopes carry top-level \texttt{id} + ISO \texttt{timestamp}, and updates re-\texttt{trace-create} the same id (v2 uses \texttt{trace-create} for updates). Posts are submitted on a small thread pool with short timeouts so tracing stays off the request loop. The same path can target the parent \texttt{components/tracing} collector on \textbf{:3000}, which appends to \texttt{/tmp/langfuse\_traces.jsonl} and exposes a Langfuse-compatible ingestion surface plus the \texttt{/observe} timeline. LangGraph Studio is the third pane, on \textbf{:2024} (panel \texttt{https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024}). A Studio run carries \texttt{request\_id} alongside \texttt{messages}---the same id sticky MemorySaver, Langfuse, and the collector use---so the graph thread joins the chat trace.

Separately, \texttt{eval\_store.py} persists enriched pipeline cards to \textbf{\texttt{/tmp/observability.db}} (WAL SQLite, \texttt{EVAL\_DB\_PATH}) and mirrors them to \textbf{\texttt{/tmp/pipeline\_traces.jsonl}} (\texttt{TRACE\_JSONL}). The observability dashboard router under \texttt{/api/observability} is how Studio/WebUI-side tooling can push ratings and stage cards into that store.

\section{5 Guard events, manager metrics, and retrieval DLQ}\label{guard-events-manager-metrics-and-retrieval-dlq}

Guardrails write terminated/allowed decisions to \texttt{/tmp/guard\_events.jsonl} (\texttt{GUARD\_EVENTS\_FILE}) with digit-run PII masking, and serve aggregates on the Persian dashboard at \texttt{http://127.0.0.1:8200/dashboard}. On the model plane, \texttt{llm\_inference\_manager} keeps session, message, and latency rows in \texttt{manager.db} and surfaces KB \texttt{stage\_ms} breakdowns when a manager-side search probe is used. When filtered retrieval returns empty, orchestrator \texttt{retrieve.py} appends a record to \texttt{/tmp/dlq\_retrieval.jsonl} so those turns stay greppable.

\section{7 Optimizations that moved the numbers}\label{optimizations-that-moved-the-numbers}

\begin{itemize}
\item
  \textbf{RAM-first tantivy + HNSW.} Rust tantivy BM25 (≈50 MB heap, RAMDirectory) and RAM-pinned dense/pgvector HNSW remove cold disk seeks from the hot path; startup pre-warm loads indexes and CUDA kernels before the first user query.
\item
  \textbf{RRF then selective rerank.} Fusion at \texttt{k=60} keeps candidate quality high while the cross-encoder scores a bounded pool (GPU, pool 30)---cheap legs stay cheap.
\item
  \textbf{Entity / context trim.} Orchestrator supplemental injection is capped (top-3 × \textasciitilde4 KB) and \texttt{prompt\_char\_budget≈20k} / \texttt{MAX\_CHUNKS=20} hold the Gemma \textbf{8192} context window. Upstream overflow is surfaced as \texttt{finish\_reason=length}.
\item
  \textbf{TRT champion serving.} On the H200, TensorRT-LLM Gemma is the throughput champion versus llama.cpp Q4 for concurrent decode. Latency planning treats generate cost as a function of tokens and concurrency, read beside KB \texttt{stage\_ms}.
\end{itemize}
