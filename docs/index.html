Work Credit RAG — Phase 1

Self-hosted, Persian-capable conversational RAG platform built on the Dana Agent Framework. Production code lives in independently maintained Git submodules with pinned commits; the parent repo owns pins, integrated startup, and E2E evaluation.

Powered by Dana Agent Framework

Repository Purpose

Work Credit RAG Phase 1 is a self-hosted, Persian-capable conversational Retrieval-Augmented Generation (RAG) platform. It provides production-grade question answering over a Persian knowledgebase with hybrid retrieval, safety guardrails, sticky conversation memory, and full observability.

The platform is deployed on self-hosted GPU (RTX 3090) and H200 hosts, serving Persian-language queries about financial credit validation, facility guarantees, and general knowledge domains through an Open WebUI frontend.

What It Does

Persian RAG Chat

Open WebUI :13000 · ICS Helper

Accepts Persian-language user messages through Open WebUI, routes them to the orchestrator, and returns grounded answers with citations and follow-up suggestions.

Hybrid Retrieval

KB :8000 · BM25 + Dense + RRF

Combines BM25 tantivy keyword search, dense MiniLM-384 semantic search, and BGE-m3 reranking with Reciprocal Rank Fusion (k=60) over 1123 chunks in pgvector HNSW.

Safety Guardrails

Guardrails :8200 · Persian Rails

Validates input and output for Persian safety signals (toxicity, hate, PII, injection) using deterministic signals plus an LLM judge, with fail-closed behavior.

Sticky Memory

LangGraph · MemorySaver

Maintains conversation context via X-Request-ID sticky threads, preserving applied subspace and filter_path across turns for coherent multi-turn dialogue.

Observability

Collector :3000 · Langfuse :3001

Captures full request traces to SQLite and Langfuse, with a unified dashboard showing 8-stage chunk cards, subspace badges, and JSONL/CSV export.

Generation

Gemma 4 31B · :18000 / :9000

Generates answers using Gemma 4 31B Instruct (unsloth GGUF quantized) via direct llama-server on self-hosted GPU or the LLM Inference Manager on H200.
