\chapter{Deep Dive: Guardrails \& Security}\label{deep-dive-guardrails-security}

\section{Section summary}\label{section-summary}

Guardrails (\texttt{Work\_RAG-Guardrails}, port \texttt{:8200}) is the mandatory safety boundary between the LangGraph orchestrator and the Gemma inference plane. Every user turn is checked on the \emph{input} stage before retrieval context is answered; every completed assistant reply is checked again on the \emph{output} stage before it returns to WebUI. The path is deterministic evidence signals, then an adjudicating judge (\texttt{gemma}, \texttt{mizan}, or \texttt{hybrid}), then a direct-LLM yes/no self-check. Policy text ships as versioned YAML; the credit pin is \texttt{policies/ics-credit-v1.0.0.yaml}. HurtLex hate checks consult an exact-word allowlist of \textbf{28} lemmas. Iranian PII on allowed answers is masked after mod-11 (national ID) and mod-97 (Sheba / IR-IBAN) checks; secret markers hard-block. Ghadeer mmBERT operating points published with the stack are toxicity \textbf{0.80}, hate \textbf{0.80}, PII \textbf{0.90}, and injection \textbf{0.85}. Judge timeout, empty verdict, or transport error fails \emph{closed}.

\texttt{collect\_signals} normalizes Persian text and runs pattern/list detectors. Those hits are \emph{helpers for the judge}, and \texttt{secret} (\texttt{sk-}, \texttt{api\_key}, \texttt{database\_url}, \texttt{Bearer}) is the detector \texttt{adjudicate} short-circuits to refuse. Domain keywords from the active policy feed a fast out-of-domain pre-check. An absent policy file or an empty keyword list routes to review.

The HurtLex detector reads \texttt{kb/hurtlex\_allowlist.json}: \textbf{28} lemmas matched as exact words on both input and output, chosen so credit and social vocabulary (حذف، تأمین مالی، اشتغال، مردم، and the rest of that list) stays in domain. Profanity, PII, and secret checks stay outside that allowlist.

Output-stage \textbf{PII-IR} is checksum-aware, not a bare digit hunt. A national ID must satisfy the Iranian mod-11 check; a Sheba / IR-IBAN must satisfy mod-97; mobile and landline patterns are matched alongside those validators. A valid PII hit on an otherwise allowed answer is \textbf{mask-and-continue} (\texttt{{[}masked-pii{]}}). A secret marker is a hard block. The events log stores only the masked form.

Judge backend is selected with \texttt{GUARD\_JUDGE\_BACKEND}:

\begin{itemize}
\item
  \textbf{\texttt{gemma}} (default) --- pinned-policy categories judged by Gemma; parse \texttt{VERDICT} / \texttt{CATEGORY}; empty or unparseable → refuse.
\item
  \textbf{\texttt{mizan}} --- Mizan System-1 via Manager (\texttt{/systemone}) with calibrated safety / scope / severity questions.
\item
  \textbf{\texttt{hybrid}} --- Mizan first; escalate to Gemma when confidence is low, severity is high, or hard signals fire (injection, jailbreak, secret, PII, hate, offense).
\end{itemize}

\texttt{GUARD\_JUDGE\_MODE=on-signal} (default) skips the LLM judge when the text is clean; \texttt{always} forces adjudication. A second-opinion direct-LLM yes/no self-check is fail-closed on error. \texttt{GUARD\_NEMO\_SELFCHECK} (\texttt{on} / \texttt{shadow} / \texttt{off}) selects that self-check.

Published Ghadeer mmBERT score floors, from the parent models table, sit next to those detectors: toxicity \textbf{0.80}, hate \textbf{0.80}, PII \textbf{0.90}, injection \textbf{0.85}. They are operating points for the classifier signals, not a second policy language. The category taxonomy the judge actually returns is \texttt{prompt\_injection}, \texttt{jailbreak}, \texttt{hate}, \texttt{offense} (profanity), \texttt{pii}, \texttt{out\_of\_scope}, \texttt{secret}, \texttt{policy}, and \texttt{engine\_error}.

\section{Policy pin}\label{policy-pin}

Versioned prompts live under \texttt{policies/} as \texttt{policies/\textless{}domain\textgreater{}-v\textless{}semver\textgreater{}.yaml}. \texttt{policies/active.yaml} is the pin. The current credit file is \texttt{policies/ics-credit-v1.0.0.yaml}: company and people mentions count as in-domain, and ungrounded advice is its own refusal category. Each file carries \texttt{id}, \texttt{version}, \texttt{stage}, and \texttt{categories} whose \texttt{prompt} interpolates \texttt{\{\{text\}\}} and \texttt{\{\{signals\}\}}, plus \texttt{refusal}, \texttt{examples}, and \texttt{domain\_keywords} for the no-LLM scope pre-check. Released versions are immutable; a change is a new file and a moved pin. The reported default \texttt{POLICY\_VERSION} when nothing is pinned is \texttt{mvp-1}.

\section{Endpoints and user-facing policy}\label{endpoints-and-user-facing-policy}

\textbf{\texttt{POST\ /v1/rails/check}} accepts \texttt{\{stage,\ text,\ request\_id\}} for \texttt{input} or \texttt{output}. The response carries \texttt{allowed}, \texttt{action}, category ids, and a \texttt{reason} string. In production mode (\texttt{GUARD\_RESPONSE\_MODE}), \texttt{reason} is a premade Persian message keyed by category---prompt injection, jailbreak, hate, offense, out-of-scope, PII, secret, policy---without exposing regex matches or judge traces. Output-stage hate/profanity refusals blame the \emph{answer} (``پاسخ حاوی محتوای نامناسب است\ldots{}'') rather than the user.

\textbf{\texttt{POST\ /v1/chat/completions}} is the OpenAI-compatible guarded gateway used by the orchestrator's \texttt{guarded\_generate} node. Flow:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  Extract the question slice from an augmented user message (\texttt{Question:} / \texttt{سوال:}), cap to the rails text limit.
\item
  Input rails → refuse with \texttt{finish\_reason="content\_filter"} if blocked.
\item
  Trim chat history to a Persian-aware char budget so upstream context (8192 tokens) is not overflowed.
\item
  Call Gemma with \texttt{chat\_template\_kwargs:\ \{"enable\_thinking":\ false\}} and strip leaked control tokens.
\item
  Output rails → refuse or continue.
\item
  If PII-IR validators (national-id mod-11, Sheba mod-97, phone patterns) still match an \emph{allowed} answer, \texttt{events.mask\_text} replaces those digit runs---and API-key-like spans---before return.
\end{enumerate}

Health and readiness expose upstream reachability and policy version; the interactive dashboard aggregates masked JSONL events (block rate, categories, 24h timeline, sample viewer).

\section{Upstream contract details}\label{upstream-contract-details}

All outbound \texttt{httpx.AsyncClient} calls to the manager on \texttt{:9000} set \textbf{\texttt{trust\_env=False}}. That flag keeps loopback traffic off the host Squid proxy at \texttt{192.168.203.2:3128}. See the server-setup section for the same rule on the manager.

The gateway maps timeout and context-window paths to \textbf{\texttt{finish\_reason="length"}} with a short Persian retry hint. Successful rails refusals use \texttt{content\_filter}; clean answers use \texttt{stop}. The allowed set is \texttt{stop}, \texttt{length}, and \texttt{content\_filter}.

Buffered completions run input rails, call the manager, run output rails, and write a masked JSONL event. The dashboard reads that log.
