\section{Section summary}\label{section-summary}

Work Credit RAG is a Persian-first, self-hosted conversational system that answers credit-reporting questions from a versioned ICS knowledge base. A LangGraph orchestrator retrieves evidence, and a fail-closed guardrails gateway stands in front of Gemma. Production code lives in Git submodules. The umbrella repository owns pins, contracts, evaluation, and host startup scripts.

The current knowledge-base release, \texttt{v13\_1405-07-06}, holds \textbf{18 documents} and \textbf{1,123 chunks}. Guardrails suppresses credit-domain HurtLex false positives with an allowlist of \textbf{28} lemmas. Subspace ambiguity is computed on every eligible turn; by default \texttt{subspace\_ambiguity\_enabled} is \textbf{true} and \texttt{subspace\_ambiguity\_route} is \textbf{false}, so the score is recorded for audit while graph routing continues to use the established clarify and retrieve edges.

\section{Hosts in production practice}\label{hosts-in-production-practice}

Production runs on the \textbf{H200} lab host. The LLM Inference Manager on \texttt{:9000} fronts an 11-model registry whose champion is \texttt{gemma-4-31b}. Embedding servers and the Gemma pool are host processes. Redis, pgvector, and Open WebUI sit on a Docker data plane. The orchestrator's published upstream model name on this host is \texttt{gemma-4-31b-triton-trt}.

The MVP path is a fixed hop list. Open WebUI (\texttt{:13000}) calls the orchestrator's OpenAI-compatible API (\texttt{:8100}). The orchestrator validates input through guardrails (\texttt{:8200}), retrieves from the knowledge base (\texttt{:8000}), builds a bounded prompt, and generates through the same guardrails service. Gemma is reached from guardrails via the LLM manager on \texttt{:9000}. Citations return to WebUI. Traces land in Langfuse (\texttt{:3001}) or the JSONL fallback collector (\texttt{:3000}).
