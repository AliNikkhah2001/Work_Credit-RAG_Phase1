Paper Summaries

MTRAG: The Gold Standard Benchmark

Field Detail
Title MTRAG: A Multi-Turn Conversational Benchmark for Evaluating Retrieval-Augmented Generation Systems
Authors Katsis et al. (IBM Research)
Venue ACL 2025 (arXiv:2501.03468)
Benchmark https://github.com/ibm/mt-rag-benchmark

Key Stats:

  • 110 conversations, 7.7 turns avg, 842 turns total
  • 4 domains: ClapNQ, FiQA, Govt, Cloud
  • 777 answerable turns (after filtering unanswerable)
  • 16.9 unique relevant passages per conversation
  • 87% non-standalone turns (require context)
  • 13% clarification turns, 74% follow-up

Retrieval Evaluation:

  • Metrics: nDCG@1/3/5/10, Recall@1/3/5/10
  • Models: Lexical (BM25), Dense (BGE, E5), Sparse (ELSER)
  • Settings: Last-turn only vs Query rewrite

Generation Evaluation:

  • Models: 9 LLMs evaluated
  • Settings: Reference, Reference+RAG, Full RAG
  • Human eval: Rigorous annotation

Key Finding: ELSER R@5 drops 0.89 → 0.47 (first → later turns) = 51% degradation

MTRAGEval: SemEval 2026 Task 8

Field Detail
Title SemEval-2026 Task 8: MTRAGEval - Evaluating Multi-Turn RAG Conversations
Venue SemEval 2026 (ACL Anthology: 2026.semeval-1)
Subtasks A: Retrieval (nDCG@5), B: Generation with gold, C: End-to-end RAG

Benchmark: MTRAG-UN (unanswerable, underspecified, non-standalone)

  • 842 multi-turn dialogues across 4 domains
  • Domains: ClapNQ (26.6%), FiQA (23.6%), Govt (25.4%), Cloud (24.4%)
  • Task A: nDCG@1/3/5/10, Recall@1/3/5/10
  • Task C: Harmonic mean of quality + faithfulness (IDK-conditioned)

Evaluation Metrics

Retrieval Metrics

Metric Formula Use Case
nDCG@k Normalized Discounted Cumulative Gain Ranking quality
Recall@k Fraction of relevant in top-k Coverage
MRR Mean Reciprocal Rank First relevant position
Hit@k Binary: any relevant in top-k Binary success

Generation Metrics (RAGAS)

Metric Description Higher Better
Faithfulness Answer grounded in contexts ✅
Answer Relevancy Answer addresses question ✅
Context Relevancy Retrieved chunks relevant to question ✅
Context Recall Fraction of answer covered by context ✅
Hallucination Facts not in context ❌ (lower better)

Reproduction

# Full benchmark (214s)
cd Work_Credit-RAG_Phase1
PYTHONPATH=".:components/orchestrator:$PYTHONPATH" python3 -m evaluation.bench_runner

# RAGAS evaluation
PYTHONPATH=".:components/orchestrator:$PYTHONPATH" python3 -m evaluation.ragas_eval \
  --input evaluation/artifacts/bench_results_latest.json \
  --output evaluation/artifacts/ragas_results_latest.json

# Report generation
PYTHONPATH=".:components/orchestrator:$PYTHONPATH" python3 -m evaluation.report \
  --bench evaluation/artifacts/bench_results_latest.json \
  --ragas evaluation/artifacts/ragas_results_latest.json \
  --out evaluation/artifacts/bench_report_latest.html
