\section{Shared repo}

Frontend work happens in the Open WebUI fork:

\begin{itemize}
  \item GitHub: \url{https://github.com/AliNikkhah2001/Work_RAG-WebUI}
  \item In the umbrella repo it lives at \pathbox{components/webui}

\section{How we customize Open WebUI}

\begin{enumerate}[leftmargin=1.4em, itemsep=0.25em]
  \item Theme packs as JSON under \pathbox{static/dana/themes/} (colors, logo, empty copy, backgrounds).
  \item \pathbox{src/lib/dana/theme.ts} loads a pack, sets CSS variables, \texttt{WEBUI_NAME}, RTL, \texttt{localStorage}.
  \item \pathbox{static/dana/dana.css} styles glass bubbles / empty state when \texttt{html.dana-theme} is set.
  \item \pathbox{DanaChatBackground.svelte} draws motion / still background from the pack.
  \item Magic widgets parse allowlisted tokens in assistant text (\pathbox{src/lib/components/dana/magic/}).
  \item After changing \pathbox{static/dana/}, copy into \pathbox{backend/open_webui/static/dana/} (or rebuild image).
\end{enumerate}

Default theme id: \texttt{ics-maroon}. Override with \texttt{?dana_theme=<id>} or env \texttt{DANA_THEME_ID}.

\section{Connect Open WebUI $\rightarrow$ orchestrator}

WebUI talks only to the orchestrator OpenAI-compatible API.

\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
\textbf{Service} & \textbf{Local} & \textbf{Role} \\
\midrule
WebUI & \texttt{:13000} & Chat UI \\
Orchestrator & \texttt{:8100} & RAG agent API \\
\bottomrule
\end{tabular}
\end{center}

Compose / env (laptop):

\begin{lstlisting}
OPENAI_API_BASE_URL=http://127.0.0.1:8100/v1
OPENAI_API_KEY=sk-local-dev
WEBUI_NAME=دستیار اعتباری نوین ایران
DEFAULT_INTERFACE_SETTINGS={"dana_theme_id":"ics-maroon","params":{"stream_response":true}}
\end{lstlisting}

Model id from orchestrator: \texttt{ics-helper-agent}\\
Chat: \texttt{POST /v1/chat/completions} (SSE when \texttt{stream:true})\\
Full request/response contract: parent doc \pathbox{docs/frontend-rag-api.pdf}

\section{Testing designs}

\subsection{A --- Dummy / mock agent (UI only)}

Point WebUI at any OpenAI-compatible mock that streams SSE chunks shaped like:

\begin{lstlisting}
data: {"choices":[{"delta":{"content":"hello "}}]}

data: {"choices":[{"delta":{},"finish_reason":"stop"}]}

data: [DONE]
\end{lstlisting}

Examples: a tiny local FastAPI/Flask stub, or tools such as \texttt{prism} / mock servers. Keep \texttt{OPENAI_API_BASE_URL} aimed at the mock. Useful for theme, RTL, empty state, and glass work without RAG.

\subsection{B --- Real orchestrator}

\begin{lstlisting}
# health
curl -s http://127.0.0.1:8100/health

# non-stream
curl -s http://127.0.0.1:8100/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer sk-local-dev' \
  -H 'X-Request-ID: ui-test-1' \
  -d '{"model":"ics-helper-agent","messages":[{"role":"user","content":"سلام"}],"stream":false}'

# stream
curl -N -s http://127.0.0.1:8100/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer sk-local-dev' \
  -H 'X-Request-ID: ui-test-2' \
  -d '{"model":"ics-helper-agent","messages":[{"role":"user","content":"اعتبارسنجی چیست؟"}],"stream":true}'
\end{lstlisting}

Then open \url{http://127.0.0.1:13000} and \url{http://127.0.0.1:13000/static/dana/design-gallery.html}.

\subsection{Local rebuild tips}

\begin{itemize}
  \item Static-only CSS/JSON/HTML: copy into the running container under \texttt{/app/backend/open_webui/static/dana/} or rebuild WebUI image.
  \item Svelte changes: \texttt{npm run build} in the WebUI repo, then recreate the \texttt{webui} compose service.
  \item Hard-refresh the browser (theme id is cached in \texttt{localStorage}).
\end{itemize}

\section{Speed checklist}

\begin{itemize}
  \item Edit \pathbox{static/dana/themes/ics-maroon.json} for white-theme tokens/copy first.
  \item Tune glass/empty-state in \pathbox{static/dana/dana.css}.
  \item Preview variants in the design gallery before full chat rebuild.
  \item Keep magic widgets allowlisted in \pathbox{magic-tokens.json}.
  \item Sync \pathbox{backend/open_webui/static/dana/} whenever you touch \pathbox{static/dana/}.
  \item PR against WebUI \texttt{develop}; parent umbrella only advances the submodule pin.
\end{itemize}
