\section{چگونه UI را روی Open WebUI ساختیم}

\begin{enumerate}
  \item پک تم JSON در \texttt{static/dana/themes/} (مثلاً \texttt{ics-maroon} سفید/روشن).
  \item \texttt{theme.ts} پک را می‌خواند، متغیرهای \texttt{--dana-*}، RTL، نام محصول و \texttt{html.dana-theme} را ست می‌کند.
  \item \texttt{dana.css} ظاهر شیشه‌ای و empty-state را روی برند فعال می‌کند.
  \item \texttt{DanaChatBackground.svelte} پس‌زمینه موشن/still را از پک می‌کشد.
  \item ویجت‌های جادویی از توکن‌های allowlist در پاسخ دستیار رندر می‌شوند.
  \item بعد از تغییر \texttt{static/dana/}، به \texttt{backend/open\_webui/static/dana/} هم کپی کنید (یا image را rebuild کنید).
\end{enumerate}

\section{تست طراحی}

\subsection{A --- Mock OpenAI (فقط UI)}

هر سرور سازگار با OpenAI که SSE بدهد:

\begin{lstlisting}
data: {"choices":[{"delta":{"content":"سلام "}}]}

data: {"choices":[{"delta":{},"finish_reason":"stop"}]}

data: [DONE]
\end{lstlisting}

\texttt{OPENAI\_API\_BASE\_URL} را به mock بزنید --- برای تم، RTL، empty-state، بدون RAG.

\subsection{B --- ارکستراتور واقعی}

\begin{lstlisting}
curl -s http://127.0.0.1:8100/health
curl -s http://127.0.0.1:8100/v1/models
curl -s http://127.0.0.1:8100/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer sk-local-dev' \
  -H 'X-Request-ID: ui-1' \
  -d '{"model":"ics-helper-agent","messages":[{"role":"user","content":"سلام"}],"stream":false}'
\end{lstlisting}

سپس: \url{http://127.0.0.1:13000} و گالری تم.

\subsection{بازسازی محلی}

\begin{itemize}
  \item فقط CSS/JSON/HTML: کپی به کانتینر \texttt{/app/backend/open\_webui/static/dana/}
  \item تغییر Svelte: \texttt{npm run build} سپس recreate سرویس \texttt{webui}
  \item Hard-refresh؛ در صورت نیاز \texttt{localStorage.dana.theme\_id} را پاک کنید
\end{itemize}

\section{چک‌لیست سرعت}

\begin{itemize}
  \item اول \texttt{ics-maroon.json} و \texttt{dana.css}
  \item گالری قبل از rebuild کامل
  \item sync کردن \texttt{backend/open\_webui/static/dana/}
  \item magic فقط از allowlist
  \item PR روی WebUI \texttt{develop}؛ umbrella فقط pin را جلو می‌برد
\end{itemize}
